# EDSA Native Power Tracker

A professional, location-verified operational platform for electricity status reporting and hazard escalation in Freetown, Sierra Leone.

## 🚀 Features

- **Live Tracker**: Community-driven power status signals with automatic GPS area detection.
- **Hazard Escalation**: Report dangerous lines, falling poles, and illegal connections with photo evidence.
- **Admin Command**: Centralized dashboard for operational oversight and data export.
- **Future Direct Vending**: A credentials-gated integration boundary and reconciliation-ready transaction model for a future authorized EDSA vending aggregator service. It remains disabled until formal approval and gateway credentials are in place.
- **Mobile-First Design**: Premium, native-style interface optimized for field agents and citizens.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Database**: PostgreSQL (Prisma ORM)
- **Styling**: Tailwind CSS & Framer Motion
- **Icons**: Lucide React

## Direct EDSA Vending Preparation

Direct token vending is intentionally disabled. After BridgeTech receives an authorized EDSA aggregator agreement and gateway documentation, configure the `EDSA_VENDING_*` environment variables from `.env.example`, implement the approved STS gateway adapter, validate it in the provider sandbox, and enable it through the Operations Console.
